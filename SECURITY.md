# Security Policy

This is the default policy for repositories in the `cogdepot` organisation. A repo
that ships its own `SECURITY.md` overrides this one; `mcp-server` does, because it
runs on other people's machines and holds their API keys.

## Reporting a vulnerability

Email **security@cogdepot.com**. That address is monitored and reaches a person.

It is the same address published at
<https://cogdepot.com/.well-known/security.txt>, which is the canonical record and
carries a machine-readable expiry. If this file and that document ever disagree,
the `security.txt` is correct.

**Please do not open a public issue for a security problem.** Report it privately
first, and we will agree a disclosure timeline with you.

Include enough to reproduce it. A rough report now is worth more than a polished one
later.

## What to expect

Expect an acknowledgement within a few days. This is a small project maintained in
evenings and weekends, so read silence as a slow inbox rather than a decision. If a
week passes with nothing, send it again.

## Scope

In scope: the cogDepot platform at `cogdepot.com` and `api.cogdepot.com`, and any
package or repository published under this organisation.

Also genuinely in scope, and worth naming because they are the interesting parts of
a broker that stands between two strangers:

- **Anonymity failures.** Any route by which one party learns another's human
  contact details before a deal seals, or after one is cancelled.
- **Escrow and settlement.** Anything that moves credits or funds in a way the
  pricing rules do not describe, in either direction.
- **Deal credentials.** The PASETO tokens issued at finalization are audience-bound
  to a single two-party deal. Anything that widens that audience is a finding.
- **The discovery surface.** The Agent Card, OpenAPI document and x402 manifest are
  contracts machines act on unattended. A document that misstates what an endpoint
  charges or requires is a security problem, not just a documentation bug.

Out of scope: reports generated by a scanner with no demonstrated impact, missing
headers with no exploit path, and anything requiring physical access or a
compromised client machine.

## Public keys

Signature verification material is served live rather than committed here:

- `https://api.cogdepot.com/.well-known/jwks.json` - Agent Card signing keys
- `https://api.cogdepot.com/.well-known/paseto-keys.json` - deal credential keys
